📝 Gestor de Tareas – Flask App

Aplicación web construida con Flask que permite a los usuarios registrarse, iniciar sesión y gestionar sus tareas personales. Diseñada como un proyecto práctico para demostrar habilidades en desarrollo backend, manejo de sesiones y organización de un proyecto web real.

🚀 Características Principales

🔐 Autenticación completa
Registro, inicio de sesión y cierre de sesión con contraseñas encriptadas.

🗂️ Gestión de tareas por usuario
Cada usuario puede crear y visualizar sus propias tareas.

📦 Base de datos ligera
Implementado con SQLite, ideal para proyectos sencillos y portátiles.

🎨 Interfaz limpia y minimalista
Diseñada para ser intuitiva y fácil de usar.

🧩 Arquitectura simple y mantenible
Código organizado en módulos para facilitar la escalabilidad.

🛠️ Tecnologías Utilizadas

Python 3

Flask

Flask-Login

Flask-Bcrypt

SQLite

HTML / Bootstrap

▶️ Cómo Ejecutarlo

Clonar el repositorio:

git clone https://github.com/JRicardoCasallas/task-manager-flask-app.git


Entrar al proyecto:

cd tu-repositorio


Instalar dependencias:

pip install -r requirements.txt


Ejecutar la app:

python app.py


Abrir en el navegador:

http://127.0.0.1:5000
